# WanderLust - Airbnb Clone

WanderLust is a simple Airbnb Clone project built using Node.js, Express, MongoDB and EJS.

This project allows users to:
- View Listings
- Add New Listings
- Edit Listings
- Delete Listings

## Tech Stack

- Node.js
- Express.js
- MongoDB
- EJS
- Bootstrap

## Installation

```bash
npm install
node app.js
```

## Features

- CRUD Operations
- MongoDB Integration
- Joi Validation
- Error Handling

## Future Improvements

- Authentication
- Image Upload
- Reviews and Ratings
